# 商品视觉工作流整合 · 0.2.0

## 迁移判断

| 成果 | 判断 | 处理位置 |
|---|---|---|
| 多用途/多颜色套图调度 | 已有能力增强 | product-shots，共享配置与参考绑定 |
| 连贯长页、材料独立页、尺码页 | 已有能力增强 | product-shots-detail-page，按需加载 references |
| 正侧背、标签方位、自然人物比例 | 已有能力增强 | product-shots-multi-angle 与共享质量规则 |
| 生成后检查、局部修图与导出同步 | 已有能力增强 | product-shots-image-gen、共享交付协议与校验脚本 |
| 参数到消费者文案、材料证据分层 | 已有能力增强 | ecommerce-visual-copywriting，配置与视觉交接 |
| 品牌、颜色、人物动作、材料、模块顺序 | 配置差异 | 可编辑 Profile 与每项目配置 |
| 客户页面、Logo、认证图、截图、私有数据 | 一次性案例 | 不迁入公共仓库 |
| ecommerce-image-suite | 路由/交付能力重叠 | 不新增，需求归入 product-shots |
| ecom-details-image | 参考编辑能力重叠；独立包许可未确认 | 不复制该包源码，编辑能力由已有生成执行器覆盖 |

技能总数维持 9，分类不变，服装开发技能文件未修改。品牌名称、指定人体身高、场景道具、材料成分和特定尺码表不进入通用默认事实。

## 旧规则收敛

商品视觉旧版 references 中的固定问答轮次、固定九图/七页、无来源转化率提升数字、固定行业配色禁令、平台数值表和未确认授权的远程样例图片已退出执行链并移除。替换为本仓库的任务边界、可编辑配置、产品保真、证据分层、按需视角与结果验证文件。历史版本仍可通过 Git 查看，不放回运行上下文。
