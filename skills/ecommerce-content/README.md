# 分类：电商文案

把产品事实、平台、人群和视觉参考转成可直接执行的详情页、Listing、A+ 和图内文案方案。

- [`ecommerce-visual-copywriting`](ecommerce-visual-copywriting/README.md)：视觉策略、Storyboard、图内文案、Prompt 与合规证据检查。

通过 [文案输入模板](ecommerce-visual-copywriting/assets/input-template.json) 调整市场、文案语言、人群、语气与输出层级。需要图片时将证据与任务卡交给商品视觉流程，避免重复规划或把文案稿当作图片交付。
