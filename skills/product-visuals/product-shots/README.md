# product-shots

## 一句话定义

商品视觉的总入口：根据产品原图、平台和用途，把任务路由到主图、详情页、广告、社媒或多角度 Skill。

## 它解决什么

用户往往只说“帮我做一套商品图”。这个 Skill 先判断是商品列表、A+、广告还是社媒任务，再交给正确的子 Skill，避免用同一套构图规则硬套所有平台。

## 输入

- 真实产品原图或已认可的产品参考；
- 目标平台、用途、图片数量与语言；
- 已证实卖点、品牌素材和必须保留的结构。

## 输出

- 任务路由与最小补充信息；
- Product Lock 与证据边界；
- 对应子 Skill 的实际图片交付和质量检查。

## 边界

不凭空增加产品结构、包装、认证、评分、销量或功效。仅做 brief 或优化 Skill 时，不声称图片已生成。

## 调用示例

```text
用 product-shots 根据这组产品原图，判断我的 Amazon 主图、A+ 和 Instagram 素材应分别走哪个流程，然后直接执行。
```
