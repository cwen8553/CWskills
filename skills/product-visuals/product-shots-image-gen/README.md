# product-shots-image-gen

## 一句话定义

商品图生成与编辑的执行器：使用宿主提供的内置生图能力，并在交付前实际检查产品保真、文字、像素和构图。

## 它解决什么

- 每张图都绑定原始产品参考，减少多代生成漂移；
- 生成后打开实际文件，而不是只看任务状态；
- 内置生图失败时不自动切换到付费第三方服务。

## 输入

最终 Prompt、真实参考图、图片数量与比例、保真要求和输出目录。

## 输出

实际图片文件、可见预览、已核对项、未确认项和需要返修的具体缺陷。

## 安全边界

- 该 Skill 不搜索、读取或上传本机 API key。
- 不自动切换到外部网关、付费 API 或其他生图工具。
- 关键产品结构连续两次仍漂移时停止盲目重试，说明缺陷并交付候选。
