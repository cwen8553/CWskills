# product-shots-detail-page

## 一句话定义

将真实商品、材料证据、模特图和详情页参考组织成连贯长页，并输出可拆分的 Amazon A+ 或 PDP 模块。

## 它解决什么

- 详情页变成多张不相干的单图；
- 模特、商品、颜色与材料信息在模块间漂移；
- 尺码页将人体尺码和成衣尺寸混在一起；
- 概念长图被误当成可直接上传的 A+ 文件。

## 输入

商品原图、已认可款式、可用卖点证据、目标平台与模块、页面参考和品牌素材。

## 输出

整页节奏与缩略预览、连贯长图、可拆模块、尺码/材料/颜色页，以及上传前的规格检查。

## 边界

页面模块数量由购买问题和证据决定，不固定为某个数量。精确 Logo、标签和尺码使用原件或可编辑排版，不依赖生成模型猜写。

## 调用示例

```text
用 product-shots-detail-page 把这组模特图、材料细节和尺码表整理成一张连贯详情长图，同时拆出 Amazon A+ 模块。
```
