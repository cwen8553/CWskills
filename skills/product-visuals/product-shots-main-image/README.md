# product-shots-main-image

## 一句话定义

基于真实商品参考，制作 Amazon US 等商品列表需要的白底主图和证据型英文副图。

## 何时使用

- 白底 MAIN 图；
- 商品细节/利益副图；
- 场景副图；
- 已有 listing 图片的保真、合规和可读性检查。

## 输入

原始产品图、款号/变体、包含物、目标类目、已证实卖点和图片数量。

## 输出

白底主图、单一购买问题驱动的副图、产品一致性检查、实际像素与英文可读性检查。

## 核心边界

- 当前 Amazon 图片规则必须以官方最新来源复核。
- 图内卖点需有产品或文档证据。
- 副图可引用已通过主图保持风格，但原始产品图仍是产品真源。
- 不承诺生成图一定通过平台审核。

## 调用示例

```text
用 product-shots-main-image 为这款商品做 1 张 Amazon US 白底 MAIN 和 2 张英文副图，不增加未证实的材料功效。
```
