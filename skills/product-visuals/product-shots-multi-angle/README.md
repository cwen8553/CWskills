# product-shots-multi-angle

## 一句话定义

以一张真实人物或产品参考为身份锁定，制作同一模特、造型和摄影风格下的多角度系列图。

## 何时使用

适合商品详情、品牌型录和社媒需要同一人物正面、侧面、背面、特写与动态角度时。

## 输入

- 必须有真实参考图；
- 可选摄影风格、背景、比例和角度清单；
- 需要保留的发型、配饰、服装和裁切边界。

## 输出

默认为一组统一的 9 角度图，包括正面、侧面、背面、特写与动态变化；数量可按用户要求调整。

## 核心边界

- 没有参考图不启动身份一致性流程。
- 参考图没有展示的背面结构必须标记不确定，不把推测当事实。
- 裁切范围是可验证硬约束，不能用“大概特写”替代。
- 建议批量生成同一组，降低分批模型漂移。

## 调用示例

```text
用 product-shots-multi-angle 按这张模特照生成 9 个一致角度，发型、服装、配饰和背景风格都不要变。
```
