# product-shots-ad-creative

## 一句话定义

按平台、版位、投放目标、行业与品牌素材制作广告创意，并检查安全区、文字、CTA 和产品保真。

## 它解决什么

避免用一张通用海报套所有平台，也避免在生图 Prompt 里混入平台 UI、假按钮、假评分或未经确认的优惠信息。

## 输入

平台、版位、广告目标、行业、产品/人物素材、品牌色/字体/标识，以及必须逐字保留的品牌名、标语、CTA、价格或优惠。

## 输出

广告构图、图内文字层级、生图 Prompt、不可出现元素、平台安全区检查和可选多变体。

## 边界

- 用户明确给出的品牌名、价格和 CTA 必须逐字保留；未给出的不补造。
- 目标平台的尺寸、安全区和文字规则必须按当前规则复核。
- 图片生成与付费投放是两个不同的授权动作。

## 调用示例

```text
用 product-shots-ad-creative 为这款产品做 Instagram Feed 转化广告，保留我给的品牌名、价格和 CTA，先交付两个构图变体。
```
