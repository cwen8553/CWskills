# apparel-techpack-production

## 一句话定义

把服装款式图、技术图、面料表、品牌规则、尺码和市场证据，转成可编辑的 XLSX/PDF 工艺单、备货建议与成本输入模板。

## 它解决什么

- 套装上衣与下装混在一张工艺单里；
- 款式与面料的透明度、克重、弹性或垂感不匹配；
- 人体尺码与成衣 POM 混用；
- Pantone、销量、评价、成本和用料被凭空补齐；
- 客户文件与内部成本逻辑被混进生产工艺单。

## 何时使用

适合新款开发、工艺单修订、多款批量打包、美国市场对标、颜色与尺码测品分配、成本表搭建和产品卖点写作。

## 最小输入

- 款式效果图或设计稿；
- 面料成分、克重、幅宽与颜色资料；
- 目标市场、尺码范围、品牌和款号规则；
- 已有技术图、样衣实测或供应商数据（如有）。

## 交付

- 每件服装独立 XLSX 和 PDF 工艺单；
- POM、BOM、工艺、三视图、标签、包装、测试和版本记录；
- 可选市场对标与每颜色/每尺码整数备货矩阵；
- 多款时的可点击管理总表、成本与大货信息填写表。

## 核心边界

- 相似款和尺码表可用于定位与拟合，不能代替成衣实测。
- 需要市场、价格、评论或趋势时必须搜索当前来源并记录日期。
- 小样备货是市场信号驱动的建议，不宣称是平台官方尺码销量。
- 未批准的 Pantone、单耗、公差、辅料价格和 MOQ 保留为待确认。

## 调用示例

```text
请用 apparel-techpack-production 把这套女士家居服拆成上衣和下装两份工艺单，并给出美国 M/L/XL 的测品分配。
```
