# 品牌与项目配置

品牌、款号和标签规则不能写死在通用流程里。每个项目复制 `assets/brand-profile-template.json` 并填写：

- 制作方品牌与客户品牌；
- 首页两个 Logo 文件；
- 文件名品牌段与工艺单标题；
- 款号前缀、数字位数、上衣/下装后缀；
- 主标、服装标识、吊牌、水洗标分别使用哪个品牌；
- 特定品类的标识位置、尺寸与公差；
- 市场、平台、默认尺码与版式语言。

Logo 文件本身不包含在通用分享包中。使用者必须放入有授权的正式文件，并在项目配置中填写相对路径。不要在公开模板中固化客户名、Logo、款号前缀或标签文案。

应用配置时，只把规则映射进当前订单 JSON。不同客户之间不得复用 Logo、品牌名、款号或标签文案。
