# 批量管理与成本填写表

## 批量管理表

多款交付时额外生成总表，每款一行，至少包含：

- 顺序、款式效果图、款号、产品名称、Excel 工艺单、PDF 工艺单；
- 板房做样/工厂做样、做样负责人、样衣状态；
- 大货负责方、大货状态、最新版本、最后更新日期、备注。

Excel/PDF 列使用相对路径超链接，保证总表与文件夹一起移动或压缩后仍可点击。若还需要总 PDF，只做目录与款式概览，不替代可点击的 Excel 管理表。

## 文件排序

- 用户指定现货款优先时，先放现货款，再按源文件自然排序。
- 保留 `源文件 -> 输出款号 -> 输出文件` 映射，避免重复、跳号和错配。
- 套装上衣与下装分别一行。

## 成本与大货信息填写表

每件成衣一行，至少包含：

顺序、状态、模特效果参考图、款号、品类、面料编号、面料名称、面料幅宽、面料用量、面料单价、工费、辅料、辅料尺寸、辅料用量、辅料单价、包装、包装用量、水洗标、主标/尺码标、总成衣成本、国内段运输费、备注。

- 总成衣成本使用公式，但空白输入必须保持空白，不能显示为已确认 0。
- 套装上衣、下装分别核算用量和成本。
- `target cost`、公开零售价和品牌售价不能替代供应商成本。
- 未经排料或样衣确认的用量标记为估算或待确认。
- 内部成本表与正式工艺单分开保存，不把利润、自动报价逻辑或供应商比较写入正式工艺单。
