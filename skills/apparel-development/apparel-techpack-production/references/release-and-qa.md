# 发布与质检规则

## 正式发布阻断项

- 缺少款号、产品名、品牌、市场、版本、负责人、基础码或尺码范围；
- 缺少已批准正面/背面技术图，或结构需要侧面但未提供；
- 效果图与技术图的袖长、衣长、部件或款式不一致；
- 套装的上衣文件混入下装技术图，或下装文件混入上衣技术图；
- 缺少颜色、主面料、POM、公差、测量方法、主要工艺、标签或包装；
- 款式与面料在遮蔽性、克重、垂感、弹性/回复或季节上存在未解决冲突；
- 固定原色没有实物色卡依据，或开发色没有实物色卡/Lab Dip 批准；
- 当前版本没有批准人；
- 市场页开启但缺少抓取日期、对标来源或每色配码合计不等于规定数量。

## 内容清洁

正式文件只出现面向客户和生产执行的内容。不得出现：

- 工具名、技能名、生成方法或技术实现；
- “AI”“内部版”“工厂版”等实现或版本标签；
- 内部成本、利润、自动报价逻辑、供应商比较、源文件绝对路径；
- 未经证实的认证、功能、销量或尺码结论。

## 文件检查

1. 运行输入验证器；正式发布必须使用 `finalize`。
2. 检查所有公式错误和空白误当 0。
3. 渲染并目检每个 Excel 工作表和 PDF 每一页。
4. 检查中文字体、图片清晰度、文字截断、分页、页码、版本和双 Logo。
5. 比对 Excel 与 PDF 的款号、颜色、BOM、POM、工艺、标签位置和配码矩阵。
6. 批量交付前打开总表链接，抽查 Excel/PDF 可达。
7. 打包后再从压缩包解压抽查一次；不要把缓存、预览图、源资料和个人绝对路径放进分享包。
